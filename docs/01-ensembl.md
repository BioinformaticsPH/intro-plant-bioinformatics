# Module 1: Ensembl

[**Ensembl**](https://beta.ensembl.org/) is a comprehensive genome browser and database project that provides a centralized resource for geneticists and molecular biologists. Originally launched in response to the Human Genome Project, it serves as a "one-stop shop" for high-quality, automated annotation of genomic data.

Unlike a simple text database, Ensembl organizes biological information spatially along the chromosomes of humans, vertebrates, and other model organisms.

* **What it does**: It maps genes, regulatory elements, and genetic variations (like SNPs) onto reference genomes.

* **Key Features**: * **Comparative Genomics**: Alignments across species to find conserved regions.

  * **BioMart**: A powerful data-mining tool for exporting large, customized biological datasets.

  * **VEP (Variant Effect Predictor)**: A vital tool for determining how specific genetic mutations might change a protein or gene's function.

## Learning Objectives
* Navigate the Ensembl interface.
* Export gene data.
